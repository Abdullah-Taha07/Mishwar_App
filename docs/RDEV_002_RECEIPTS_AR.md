- التقاط هوية الحساب قبل القراءة والتصدير، وإلغاء الطلبات وتنظيف النموذج والروابط المؤقتة ونافذة الطباعة عند الخروج أو تبديل الحساب. الرد القديم لا يعيد إيصال المستخدم السابق. لا حفظ دائم للإيصال في LocalStorage أو Cache API.
- معالجة مهلة تحميل الإيصال وفشله بإعادة محاولة صريحة؛ فشل التصدير لا يحذف بيانات الرحلة أو الإيصال المعروض. تعطيل الأفعال المتزامنة يمنع النقرات المكررة؛ تُحرَّر الروابط المؤقتة حتى عند رفض المتصفح التنزيل.
