# معالجة ثقة بوابة إدارة Worker — مراجعة محلية 23 نوفمبر 2026

## المشكلة التي أثبتها تقرير التدقيق
المعالج `apps/admin/worker/index.js` كان يثق بترويستي `oai-authenticated-user-id` و`oai-authenticated-user-email` المرسلتين مع الطلب. يمكن نسخ الترويستين في طلب HTTP مباشرة إلى Worker إن لم توجد حماية أمامية؛ لم يكن ذلك دليلاً على انكشاف بوابة Vercel أو إتاحة Worker المنشور.

## تعديل المصدر المُحضَّر (لا نشر)
- يستبدل التحقق من ترويسات العميل بهوية موثَّقة من **Cloudflare Access runtime context** (`ctx.access.getIdentity()`)، ويطلب تطابق البريد مع `ADMIN_EMAIL`.
- يعمل بمنطق **Fail Closed**: أي غياب لإعداد Access على Worker أو غياب لهوية صالحة أو خطأ يرجع HTTP 403، ولا يستطيع العميل انتحال `ctx.access` عن طريق ترويسات HTTP.
- تُمرّر الهوية الآتية من Access فقط إلى API الخلفي في `x-mishwar-admin-id` و`x-mishwar-admin-email`.
- لا يغيّر بوابة Vercel `apps/admin/api/admin/[...path].js` أو كلمة مرور مالكها أو جلسات الموظفين، ولا يُعدّل حسابات أو قاعدة البيانات.

## متطلبات النشر والتحذير التشغيلي
**لا تنشر النسخة المعدّلة من Worker الإدارة قبل التحقق من ربط تطبيق Cloudflare Access به ومن سياسة المالك.** بدون Access ستُحجب جميع واجهات Worker المباشرة HTTP 403 عمدًا. مسار Vercel مستقل وغير معدَّل في هذه الدفعة. لا ننصح بإيقاف Worker العامل إلا بعد تحديد العناوين المنشورة فعلاً ووقت النشر ونقطة التراجع.

عند اختبار البيئة التجريبية ينبغي فتح عنوان Worker تحت Cloudflare Access، والدخول بالحساب المدرج في `ADMIN_EMAIL`، والتأكد من ظهور `ctx.access` بعد مصادقة Access ومن عدم عمل طلب بدون جلسة Access. يُحظر إجراء اختبار انتحال مباشر على خدمة حية قبل تفويضه. لا تُخزن أسماء بريد أو أسرار اختبار حقيقية في المستودع.

## الاختبارات المطلوبة
1. عدم اجتياز طلب يحمل الترويسات المقلَّدة دون سياق Access.
2. رفض هوية أخرى، وغياب إعداد البريد، وأخطاء Access.
3. قبول صاحب الحساب الصحيح عبر سياق مصادق، وإرسال هويته الفعلية للخادم لا ترويسات المستخدم.
4. استمرار رفض POST من مصدر مخالف (Cross-site).
5. نجاح `npm test`, `npm run audit:source`, `npm run test:ops`, `npm run test:security` على أحدث فرع مشاركة.

**الحالة:** تعديل محلي مع فحص آلي؛ ليس تصديقاً على إعداد Cloudflare Access أو التشغيل الميداني. مراجعة بقية نقاط تقرير التدقيق واستعادة/خطة تراجع/اختبارات مزودين خارجية ما زالت مطلوبة. المصدر: https://developers.cloudflare.com/workers/configuration/cloudflare-access/
