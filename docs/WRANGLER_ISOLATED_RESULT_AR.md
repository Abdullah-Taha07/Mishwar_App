- ✅ الإعداد مستقل داخل `D:\Mishwar_App\private-backups\wrangler-isolated-sandbox-20261116`، ومعرف القاعدة الوهمي `00000000-0000-0000-0000-000000000001`. جميع أوامر D1 تتضمن `--local` ومسار حالة منفصلًا؛ لم يُستخدم إعداد الإنتاج.
- ✅ استُخدم ملف workerd الأصلي عبر `MINIFLARE_WORKERD_PATH` وبيت إعداد XDG فارغ. أزيلت متغيرات اعتماد Cloudflare والمفاتيح الخدمية من بيئة العملية. لا توجد bindings بعيدة أو بيانات اعتماد مزودين في الإعداد.

## فحص تشغيل Worker الذي استُكمل الآن

- المحاولة السابقة داخل العزل لم تبلغ الصحة الجاهزة؛ أوضح السجل الخاص تعذر قراءة مجلد تثبيت Wrangler، مع `EACCES`. لا يعني ذلك فشل ترحيلات D1 التي سبق نجاحها.
- ✅ أُعيد **هذا الفحص الناقص فقط** خارج العزل، بنفس الإعداد المعزول دون أسرار أو موارد إنتاجية. نجح في `2026-11-16T18:23:11.750Z`، الموافق **21:23:11 بتوقيت الرياض**.
- ✅ شُغّل مصدر التطبيق الفعلي `apps/hub/worker/index.js` عبر `wrangler dev --local` على loopback. أعادت `/api/health` استجابة جاهزية صحيحة باستخدام D1 وR2 محليتين.
- ✅ أضاف غلاف الاختبار المحلي مسارًا خاصًا للفحص يقرأ أعمدة `target_email` و`trip_id` و`client_request_id` المطلوبة من D1 المحلية. نجحت الاستعلامات ولم تظهر مخالفات علاقات. لم يُضف الغلاف أو مسار الفحص إلى مصدر التطبيق أو الإنتاج.
- ✅ أُوقف خادم الاختبار؛ تحقق أمر مستقل من عدم وجود listener على المنفذ المحلي `18767` بعد انتهاء العملية. لا توجد عملية اختبار معروفة باقية على هذا المنفذ.

إيصال التشغيل: `D:\Mishwar_App\private-backups\wrangler-isolated-sandbox-20261116\worker-smoke.json`. الأمر المستعمل موجود محليًا في `.local-verification/wrangler-worker-smoke.mjs`، وهو مستبعد من Git ويزيل بيانات اعتماد السحابة من بيئة child process.

## حدود الدليل

- نجاح التكوين المعزول يتجاوز عائق `EPIPE` السابق، لكنه لا يحدد أي تغيير منفرد كان سببه الوحيد؛ لا يصح نسبة الخطأ إلى فساد SQL أو غياب workerd دون دليل.
- هذا فحص صحة ومخطط Worker محلي، وليس رحلة كاملة أو تجربة إرسال SMS/بريد أو دفع أو مزامنة منشورة أو رفع/تنزيل R2. وجود binding R2 محلية لا يثبت تشغيل R2 الإنتاجية.
- لم تُجرَ اتصالات API إنتاجية أو أوامر `--remote` أو تصدير إضافي أو ترحيل إنتاج أو نشر Worker أو Git Push أو تغيير تاريخ.
- ⏳ يبقى نشر الإنتاج متوقفًا على آلية إيقاف كتابة وتصريف شاملة، وتوافق حزمة التراجع، واعتماد المالك المنفصل؛ نجاح D1 المحلية لا يغلق هذه الشروط.
