# تشغيل النسخ والتحقق المحلي من D1

حماية ملفات هذه الجلسة: أُوقفت وراثة الصلاحيات العامة لمجلد `private-backups`، وأُزيل وصول مجموعتي Windows العامتين Authenticated Users وBUILTIN Users، مع إبقاء معرفات البيئة الحالية وAdministrators وSYSTEM، وإضافة صلاحية صريحة موروثة لحساب Windows التفاعلي الخاص بالمالك. حُفظت نسخة ACL سابقة محليًا داخل `.local-verification`، وتحقق قارئ مستقل من النسختين بعد التغيير. هذا ضبط NTFS محلي؛ ليس تشفيرًا أو حماية من فقد القرص. لا تنسخ أوامر تغيير ACL إلى جهاز آخر دون التحقق من حساباته.

## المتطلبات ومكان الملفات

استخدم Node.js بإصدار **24.10 أو أحدث**؛ تعتمد الأدوات على `node:sqlite` وميزة التفويض لعزل استعادة SQL في الذاكرة. في هذه الجلسة استُخدم Node.js 26.13.0.

المستودع العامل هو `D:\Mishwar_App\review-workspace`. النسخ الخاصة خارج هذا المستودع، تحت:

- `D:\Mishwar_App\private-backups\primary`
- `D:\Mishwar_App\private-backups\secondary`

المجلدان على قرص D نفسه. هما موقعان محليان منفصلان للتحقق من الاستمرار؛ لا يوفران حماية من تعطل القرص أو فقد الجهاز، ولا يجوز وصفهما بنسختين على قرصين مختلفين. لم تنقل هذه الجلسة النسخة إلى وسيط مستقل.

يحتوي إيصال النسخ على المسارات والبصمات وأعداد الجداول والصفوف ونتائج الفحص فقط. احفظ ملفات SQL وSQLite والإيصالات محليًا؛ لا ترفعها إلى GitHub أو المحادثة. لا تطبع رموز الدخول أو رابط التنزيل الموقّع، ولا تستخدم أمر `wrangler auth token` مباشرةً للطباعة في الطرفية. تستخلص الأداة بيانات الدخول داخل العملية وتلتقط مخرجات Wrangler داخليًا عند الحاجة إلى تحديث OAuth.

## أوامر التشغيل

الأوامر التالية لـPowerShell، وتُنفَّذ من جذر المستودع العامل. لا تحتاج أوامر `probe` و`verify` إلى Cloudflare.

```powershell
Set-Location 'D:\Mishwar_App\review-workspace'
node --version
$backupPrimary = 'D:\Mishwar_App\private-backups\primary'
$backupSecondary = 'D:\Mishwar_App\private-backups\secondary'
```

### 1. إثبات بقاء ملف اصطناعي قبل أي تصدير

```powershell
$probe = node scripts/d1-backup.mjs probe $backupPrimary $backupSecondary | ConvertFrom-Json
if ($LASTEXITCODE -ne 0 -or -not $probe.receiptPath) { throw 'فشل اختبار بقاء الملفات؛ لا تبدأ تصدير الإنتاج' }
$probeReceipt = $probe.receiptPath
node scripts/d1-backup.mjs verify $probeReceipt
if ($LASTEXITCODE -ne 0) { throw 'فشل التحقق المستقل بعد انتهاء الكاتب' }
```

ينشئ `probe` ملف SQL اصطناعيًا باسم `persistence-probe-...` في المجلدين، ويغلقه بعد مزامنة الكتابة، ثم يشغل قارئًا فرعيًا مستقلًا لكل نسخة. الأمر `verify` اللاحق عملية جديدة بعد انتهاء أداة الكتابة كاملةً؛ يعيد فتح النسختين واستعادتهما في الذاكرة ومقارنة SHA256. إيصال `kind: persistence-probe` لا يُعد نسخة إنتاج.

### 2. قراءة الحالة الإنتاجية دون نشر أو ترحيل

```powershell
node scripts/d1-backup.mjs status
if ($LASTEXITCODE -ne 0) { throw 'تعذّر فحص حالة Cloudflare؛ راجع الدخول محليًا' }
```

يعرض `status` هوية D1 وإصدارات نشر Worker وأسماء وأنواع الربط وأسماء الترحيلات المطبقة. استعلامه إلى `d1_migrations` قراءة فقط. يحتاج تسجيل دخول Cloudflare صالحًا وصلاحية قراءة الموارد. إذا كان هناك أكثر من حساب، حدّد `CLOUDFLARE_ACCOUNT_ID` محليًا؛ لا ترسل مفاتيح أو رموز دخول في المحادثة.

### 3. تصدير جديد بعد نجاح إثبات البقاء

لا تشغّل هذا الأمر لمجرد متابعة التوثيق؛ النسخة المؤكدة لهذه الجلسة موجودة بالفعل. عند الحاجة إلى نسخة أحدث، يبدأ الأمر تصدير D1 حقيقيًا وقد يحجب استعلاماتها مؤقتًا؛ اختر نافذة مناسبة. الأداة تشترط إيصال اختبار بقاء من الساعة السابقة، بوقت صالح غير مستقبلي، ومن المجلدين نفسيهما.

```powershell
$export = node scripts/d1-backup.mjs export $backupPrimary $backupSecondary $probeReceipt | ConvertFrom-Json
if ($LASTEXITCODE -ne 0 -or -not $export.receiptPath) { throw 'لم يُثبت التصدير؛ لا تعلن النجاح ولا تعاود تصدير الإنتاج تلقائيًا' }
$exportReceipt = $export.receiptPath
```

تتابع الأداة طلب التصدير باستخدام bookmark، وترفض إعادة بدء الطلب عند غياب bookmark. لا ترسل رمز API إلى رابط التنزيل، وتقبل HTTPS لنطاق Cloudflare object storage فقط، وتمنع التحويلات. تحفظ النسختين بأسماء فريدة، وترفض الكتابة فوق ملفات موجودة، وتستبعد ملف TEST والمحتوى غير القابل للاستعادة.

### 4. تحقق بعد انتهاء عملية التصدير

```powershell
node scripts/d1-backup.mjs verify $exportReceipt
if ($LASTEXITCODE -ne 0) { throw 'فشل التحقق بعد انتهاء الكاتب؛ أوقف أي ترحيل أو نشر' }
```

أعد هذا الأمر لاحقًا قبل استخدام النسخة للاستعادة. النتيجة المتوقعة: `verified: true`، ومساران مختلفان، وSHA256 متطابق، و`integrity: ok`، و`foreignKeyViolations: 0`. اختفاء أي نسخة أو اختلاف بايت واحد يفشل التحقق. تحقق `verify` لا يطلب تصديرًا جديدًا ولا يتصل بقاعدة الإنتاج.

### 5. تجربة الترحيلين على النسخة المحلية

بعد التحقق من الإيصال، استخدم مجلد إخراج جديدًا لكل محاولة. يبقى المصدر دون تعديل، وتُطبق الترحيلات على SQLite محلية منفصلة:

```powershell
$sqlPath = $export.files[0].path
$rehearsalDirectory = 'D:\Mishwar_App\private-backups\rehearsal-NEW-UNIQUE-NAME'
node scripts/d1-migration-rehearsal.mjs $sqlPath $rehearsalDirectory --receipt $exportReceipt
if ($LASTEXITCODE -ne 0) { throw 'فشلت تجربة الترحيل المحلي؛ لا تطبقها على الإنتاج' }
```

هذا فحص محلي مرتبط ببصمة المصدر وإيصال تصدير الإنتاج. يتضمن حفظ بيانات الجداول الأصلية وتسلسلات المعرّفات، وفحص العلاقات والتكامل، وقيود الرسائل والدعم، وإعادة فتح القاعدة المكتوبة، وإثبات بقاء المصدر دون تغيير.
