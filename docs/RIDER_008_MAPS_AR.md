## العيوب المعالجة

- اشتراط المسارات التجارية كان يسمح باستعمال OSRM إذا غاب مفتاح TomTom أو عُطّل TomTom. أصبح هذا الإعداد يمنع fallback عند نقص الإعداد أيضًا، دون تغيير سياسة التسعير.
- نتائج Search الناقصة كانت تستعمل مركز البحث كإحداثيات بديلة. تُستبعد النتيجة غير الصالحة الآن. تدعم خدمة reverse صيغة `latitude,longitude` الموثقة لدى TomTom، دون اختراع موقع.
- مهلة قراءة المزود أصبحت تشمل جسم JSON أيضًا. تُعقم الأخطاء، بما فيها الأخطاء ذات النص العربي أو اسم Timeout المزور، قبل إرسالها أو تسجيلها؛ لا تُكشف URL تحمل المفتاح.
- تُفصل ذاكرة البحث والعناوين حسب المزود وعنوان خدمته. تُلغى الردود القديمة عند الانتقال من Photon إلى TomTom، ويُعرض مصدر البيانات الفعلي في واجهة البحث.
- تبقى طبقة OpenStreetMap متاحة إلى أن تنجح بلاطات TomTom. يعيد فشلها الخريطة البديلة مع تحذير، دون فقد علامات الانطلاق والوجهة.

## التحقق المحلي

النتائج التفصيلية ومعرّف Commit المرحلة تُثبت عند حفظها في سجل Git. تستخدم الاختبارات استجابات مزود اصطناعية وشبكة خارجية محظورة؛ لا تعني نجاح TomTom الحقيقي أو تفعيل حساب مدفوع.

لا تغيير لـmain أو إعدادات النشر أو D1. تظل اختبارات مفاتيح TomTom الفعلية وقيود النطاق والحصص ومطابقة المسار والزحام الميداني ضمن قبول الخدمات الحقيقي قبل الاعتماد التجاري.
