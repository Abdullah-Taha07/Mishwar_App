## حدود إزالة التعرض

إزالة بيانات من نسخة Git محلية لا تنظف GitHub أو مراجع طلبات الدمج والمخابئ أو نسخ المستخدمين. تنظيف المراجع البعيدة يحتاج تنسيقًا وموافقة، وقد يحتاج طلب إزالة مراجع/مخابئ حساسة من GitHub Support. المراجع `refs/pull/*` لا تعامل كفروع يمكن فرض استبدالها بالدفع العادي. المستودع يبقى عامًا خلال الخطة كلها. [دليل GitHub الرسمي](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository).

إلغاء سر أو جلسة قديمة لا يعالج كشف البيانات الشخصية، وتنظيف التاريخ لا يعيد سرية نسخة سبق تنزيلها. يُفصل احتواء الاعتمادات عن معالجة البيانات وخطة التنظيف. لا يعاد إحياء كلمة مرور أو جلسة مكشوفة عند التراجع من نسخة قاعدة قديمة.

## النسخ الخاصة

نسخة Git الأولية كاملة المراجع وموثقة SHA256، وقد أُعيد بناؤها في مستودع bare مستقل وفُحصت refs والـCommits المطلوبة و`git fsck`. أضيفت نسخة مشفرة بحماية Windows DPAPI مرتبطة بحساب المالك، وفُكّت في عملية مستقلة وطابقت بصمة bundle الأصلية. تبقى bundle العمل ونسخة فحص الاستعادة غير المشفرتين داخل المجلد الخاص ذي صلاحيات NTFS المقيدة؛ لا يصح وصف جميع النسخ بأنها مشفرة.

DPAPI CurrentUser مرتبط بحساب Windows وملفه الشخصي؛ لم يُصدَّر مفتاح استعادة محمول لجهاز آخر. الملفات على القرص المحلي نفسه ولا تمثل نسخة خارج الجهاز. تحفظ نسخة إضافية من آخر HEAD وrefs بعد اكتمال Commits المحلية الجديدة وقبل اعتماد النتيجة المنقحة النهائية. لا تحتوي تقارير المصدر العام على مفاتيح أو بيانات حسابات خام.
