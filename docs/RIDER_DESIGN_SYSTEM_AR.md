# نظام واجهات الراكب — RIDER-012

المصدر المعتمد للرموز وحالات المكونات هو [rider-design-system.css](../apps/rider/public/rider-design-system.css)، ويُحمَّل بعد ملفات الواجهة السابقة. تبقى هندسة الخريطة والحجز في ملفاتها؛ لا يغيّر نظام العرض الأسعار أو حالات الرحلة.

| الاستخدام | الرمز والقيمة الأساسية |
|---|---|
| الهوية البترولية | `--mw-petrol: #083344` |
| التركواز | `--mw-turquoise: #06b6d4` |
| كتابة الأزرار والروابط الملونة | `--mw-accent-ink: #006579` |
| النص الثانوي | `--mw-text-secondary: #526b76` |
| السطح والسطح الهادئ | `#ffffff` و`#f3f8f9` |
| التركيز والخطر والنجاح | `#006b80` و`#a52d3c` و`#14654e` |
| المسافات | 4، 8، 12، 16، 24، 32px عبر متغيرات `--mw-space-*` |
| حواف التحكم والبطاقة واللوحة | 14، 20، 28px |
| الاستجابة والانتقال والنافذة | 150، 220، 300ms |

التركواز الفاتح لون هوية وخلفية؛ النصوص الصغيرة فوقه بترولية، والروابط تستخدم التركواز الداكن لتحسين التباين. الخط Tajawal مع بدائل نظامية؛ الحقول 16px لتجنب تكبير الإدخال غير المرغوب، والعناوين أوضح وزنًا. تعتمد المسافات المنطقية قدر الإمكان على اتجاه اللغة، ويضبط `language-boot.js` اللغة والاتجاه قبل الرسم.

الهدف المعتاد للمس 44px، ولصفوف القائمة 56px. القوائم القصيرة تتمرر عوض ضغط مناطقها وتداخلها. تستهدف النصوص العادية تباين 4.5:1. هذه أهداف تصميم، ونجاح فحص آلي لا يعادل شهادة WCAG. تفاصيل الحد الأدنى 24px واستثناءاته في [WCAG 2.2](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)، والتباين في [شرح معيار التباين](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html).

تستخدم الحركة `transform` و`opacity` واستجابة ضغط قصيرة. لا ينفذ `rider-motion.js` أي حجز أو دفع أو إعادة محاولة. يتوقف عند إخفاء الصفحة أو تقليل الحركة، ويعزل مواضع التمرير بحسب صاحب الحساب. تُكشف هندسة المسار الواردة من المزود فقط؛ لا تُخترع حركة سيارة أو إحداثيات. يحترم تتبع الكابتن والخريطة تفضيل النظام وخيار إيقاف الحركة داخل التطبيق.

حالات التحميل تستخدم `aria-busy` ونص حالة وSkeleton للبحث والأسعار. لا تبقى أسعار الفئات السابقة ظاهرة كعرض صالح أثناء إعادة التسعير. يفصل التركيز المرئي وحصر تركيز البحث واسترجاعه عن الحركة. لا تعتمد أي وظيفة أساسية على اكتمال Animation.

توجد متغيرات للوضع الداكن، لكن القبول المصوّر الحالي يخص الوضع الافتراضي الفاتح؛ يلزم فحص مستقل لبقية أوضاع العرض وقارئ الشاشة والأجهزة الحقيقية. لا تدّعي هذه المرحلة إزالة كل CSS قديم؛ استُخدمت طبقة مكونات موحدة مع تعديل محدد لقاعدة إظهار اللغة القديمة للحفاظ على الوظائف السابقة.
