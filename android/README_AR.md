# مشوار — غلاف أندرويد 0.2.0

المشغّل الجديد يستخدم Activity بسيطة وواجهة Custom Tabs الخاصة بأندرويد مع fallback إلى المتصفح الافتراضي ورسالة إعادة محاولة إذا لم يوجد متصفح. لا يعتمد على LauncherActivity من Android Browser Helper. الأيقونات ومعرفات تطبيقات الراكب والكابتن والإدارة كما هي، وversionCode=2.

مصدر MainActivity وLaunchPolicy وApkShareProvider داخل app/src/main/java. الإصدار يدعم مشاركة ملف APK المثبت عبر خيارات أندرويد؛ موفر الملف غير مصدّر، للقراءة فقط، ويمنح الملف الخاص بالتطبيق وحده باستخدام إذن URI مؤقت. لا يفتح ملفات المستخدم.

يتطلب Android 7 أو أحدث (API 24) ومتصفحًا داعمًا واتصالًا بالإنترنت. لا يضيف الغلاف خدمة GPS أصلية دائمة أو إشعارات FCM أصلية؛ هذه وظائف الويب وفق دعم المتصفح وأذونات الجهاز.

## البناء

للبناء المعتاد استخدم JDK وAndroid SDK وGradle وفق build.gradle ثم `./gradlew assembleDebug` أو `./gradlew bundleRelease`. ملفات AAB القديمة التي تحمل المشغّل السابق غير مرفقة بهذا التسليم حتى لا تعاد مشاركتها بالخطأ.

يتوفر بديل لبناء APK دون تنزيل مكتبات Gradle، باستخدام SDK 36 وBuild Tools 36.0.0 وJDK:

```
python scripts/build-sdk.py --sdk /path/to/android-sdk --key /private/debug.keystore --output /path/to/apks
```

السكربت يولد مفتاح تجربة إذا لم يوجد. احفظ المفتاح خارج Git، ولا تستخدم مفتاح debug للنشر التجاري. توقيع التحديث يجب أن يطابق توقيع النسخة المثبتة. إذا اختلف توقيع التجربة يجب إزالة النسخة القديمة قبل تثبيت الجديدة؛ بيانات الحساب على الخادم لا تحذف.

اجتاز LaunchPolicy ستة فحوص JVM: الفتح الأساسي، fallback عند فشل Custom Tabs، التعامل مع غياب المتصفحات، ورفض روابط غير موثوقة. APKs فُحص توقيعها ونسخة manifest وDEX. لم تُجرَّب على جهاز أندرويد فعلي أو محاكي في هذه الجلسة؛ لا تعد الاختبارات تأكيدًا نهائيًا لاختفاء كل كراش على الأجهزة. لم يعتمدها Google Play. يتطلب Google Play حزمة AAB وتوقيع إصدار مملوكًا لك وحساب المطور ومتطلبات المتجر.
