# مشوار: APK يفتح التطبيق داخله ويشارك نسخته المثبتة

التحديث 0.4.0 يقدم مشغل Android WebView داخل التطبيق بدل إرسال المستخدم إلى متصفح خارجي.

## ما الذي يفعله هذا التحديث؟
- APK مستقل لكل دور: راكب / كابتن / إدارة.
- يفتح واجهة التطبيق عبر HTTPS داخل نفس نافذة تطبيق Android، ويحفظ الجلسة في WebView.
- زر «مشاركة ⋮» الصغير بالأعلى يقدم «إرسال ملف APK مباشرة» باستخدام Android Sharesheet (المصدر هو ملف APK المثبت نفسه)، و«مشاركة رابط التطبيق»، و«نسخ رابط التثبيت».
- يوفر أذونات الموقع بعد موافقة المستخدم، وملف الصور والمستندات لا يفتح إلا باختيار المستخدم.
- يمنع فتح النطاقات الخارجية داخل WebView، وينقل روابط https الخارجية وتطبيقات الهاتف إلى النظام.
- لم تُفتح واجهة JS native bridge، وContentProvider غير مُصدَّر ويمنح إذن القراءة المؤقت لملف APK فقط.

## قيود عملية مهمة
- هذا التطبيق **ليس تطبيقًا أوفلاين**: الواجهات محمّلة من دومينات مشوار ويظل بحاجة للإنترنت والخادم.
- **Push Notifications في الخلفية داخل WebView ليست مساوية لإشعارات PWA/Chrome**. لا تعتبر إشعارات الخلفية جاهزة للإنتاج حتى إضافة FCM Android Native واختبار التنبيهات الفعلية على الأجهزة.
- لم تُختبر جميع مهام التسجيل/الرحلات/الخرائط/رفع المستندات على هاتف أندرويد فعلي حتى الآن.
- زر «مشاركة رابط التطبيق» يرسل عنوان `/install.html`، والذي يتيح تثبيت PWA مؤقتًا. ليس رابط APK عامًا دائمًا حتى نشر ملفات APK الموقعة على استضافة عامة.
- GitHub Actions الحالي يبني **debug APK** بمفتاح اختبار قد يختلف بين عمليات البناء. لا توزع هذه النسخة تجاريًا ولا تتوقع تحديثًا فوق الإصدار السابق دون إزالة النسخة القديمة. يجب إعداد مفتاح توقيع release ثابت محفوظ سرًا قبل إطلاق APK عام مستدام.
- بعض تطبيقات المراسلة قد تقيد إرسال ملف APK مباشرة؛ استخدم خيارات المشاركة المتوفرة في الجهاز أو شارك رابطًا عامًا بعد نشر الإصدار.

## اختبار القبول على جهاز حقيقي
1. نزّل APKات الاختبار من GitHub Actions على فرع الإصلاح فقط.
2. افتح كل APK وتأكد أن واجهة مشوار تُعرض داخل التطبيق دون تبويب Chrome جديد.
3. افتح «مشاركة ⋮» واختر «إرسال ملف APK» ثم أرسله عبر Quick Share أو تطبيق يقبل ملفات APK، وثبت نسخة المستلم وتحقق من الدور الصحيح.
4. شارك الرابط وتأكد أنه يفتح صفحة التثبيت الصحيحة.
5. اختبر تسجيل الدخول، البقاء مسجلًا بعد إغلاق التطبيق، الموقع، الخرائط، طلب الرحلة، وصولها للسائق، وتزامن الإدارة.
6. للكابتن: جرّب رفع صورة هوية أو PDF والتحقق من وصولها للإدارة.
7. اختبر إشعارات الخلفية على أجهزة وشاشات مغلقة؛ لا تعتمد عليها حتى يتم تجهيز FCM أصليًا.

## نطاق النشر
هذا التعديل مخصص لفرع التطوير فقط. لا ينشر `main` ولا يغير D1 أو Cloudflare أو Vercel.
